# Шри-Ланка — внутренний раздел базы знаний CRM

Подготовлено 06.10.2026 из 38 слайдов ITM Group: 9 курортных зон,
28 отелей, сезонность, подбор, ограничения и 12 вопросов с ответами.

`data.json` содержит структурированные записи и ссылки на источники.
`content.html` — готовое содержание редактируемой статьи.
`slides/` — читаемые JPEG-копии загруженных слайдов; в JSON сохранены
исходные имена и SHA-256 оригинальных загрузок. Сведения презентации
и результаты отдельных официальных проверок явно разделены.

Миграция `knowledgebase.0002_seed_sri_lanka` создаёт статью и сохраняет
копии слайдов в MEDIA_ROOT. Она не обновляет статью с таким же названием
и не заменяет пользовательские правки. Обратная миграция сохраняет статью.
Не удалять и не менять эти файлы после применения миграции.

Для публикации на существующем сервере:

```bash
cd /opt/sletat
git pull --ff-only origin master
docker compose -f docker-compose.prod.yml build backend
docker compose -f docker-compose.prod.yml up -d --no-deps backend
docker compose -f docker-compose.prod.yml exec -T backend python manage.py migrate
```

Статья появится в `/crm/knowledge-base` под направлением «Шри-Ланка».
Frontend пересобирать не требуется. Отдельный публичный раздел не создаётся:
чтение и редактирование доступны сотрудникам через существующую авторизацию CRM.
