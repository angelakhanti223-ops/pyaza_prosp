## Подробнее и заявка

В исходном файле отдельная форма не была подключена к CRM. Ее обработчики
содержали недопустимые переводы строки в строковых литералах, из-за чего
скрипт не разбирался. Эта форма и ее нерабочие обработчики удалены.

«Подробнее» открывает существующий диалог программы, затем «Оставить заявку»
ведет на `/request?bus_tour=ID`. Сервер разрешает ID по общему каталогу и
передает в существующий LeadForm название, даты, маршрут и минимальную цену.
Пожелания раскрыты сразу и доступны для редактирования. Они отправляются
существующим публичным API в `initial_comment` вместе с контекстом формы.

Неизвестные, повторяющиеся и некорректные ID не заполняют пожелания.
Произвольные названия из URL не принимаются. При смене выбранного тура
компонент формы создается заново, поэтому состояние предыдущей заявки
не остается. Общие кнопки в шапке, первом экране и подвале ведут на `/request`
без выбранного тура. Существующее предзаполнение круизов сохранено.
Обязательное согласие на персональные данные и связь по заявке, отдельная
необязательная рассылка и отправка без CRM cookies сохранены.

## Обновление сервера

Миграций нет. Backend нужен для каталога аналитики, frontend — для страницы,
ресурсов, формы и навигации.

```bash
cd /opt/sletat &&
git pull --ff-only origin master &&
docker compose -f docker-compose.prod.yml build backend frontend &&
docker compose -f docker-compose.prod.yml up -d --no-deps backend frontend
```

Изменения в GitHub не обновляют контейнеры VPS автоматически.
