# Звёздный маршрут 2027

Публичная страница: `/travel-horoscope-2027`. Подготовлена по приложенному «Астропрогнозу путешествий 2027, Пенза». Исходный DOCX не изменялся.

В шапке — анимированное звёздное небо и дата рождения. После полной корректной даты автоматически появляются знак, стихия и соответствующий прогноз. Кнопка переводит к результату. Можно выбрать знак вручную; предыдущая дата очищается, чтобы не оставлять противоречивый результат.

Контент: 12 знаков, 50 идей маршрутов, звёздные окна из исходного материала, попутчики, талисманы, практические советы. Это редакционная развлекательная подборка. Не перенесены категоричные обещания событий, гарантии погоды, неподтверждённый безвизовый режим на 2027 год и служебные указания по построению теста. Визовые условия и конкретный тур уточняются при подборе. Новые отели, цены и гарантии доступности не добавлялись.

Определение знаков использует календарные границы из документа; это не вычисление положения Солнца по эфемеридам. На странице объяснено ограничение для пограничных дат. Поддержаны високосные годы, переход декабря/января, проверка существования даты и запрет будущей даты.

Небо реализовано CSS: 64 мерцающие звезды, медленное движение, декоративные орбиты и планета. Нет видео, canvas, таймеров или новых зависимостей. Кнопка останавливает/возобновляет движение; `prefers-reduced-motion` отключает его. Декор скрыт от скринридера, результат объявляется через `aria-live`.

CTA маршрутов открывают существующую форму с текущими согласиями и передают знак и маршрут в комментарии. Дата рождения не отправляется в CRM, не включается в URL/события аналитики и не сохраняется приложением в storage. Поле помечено `ym-disable-keys`, чтобы Вебвизор не записывал его значение. Статистика просмотров страницы остаётся включённой.

Ссылка размещена в подвале, маршрут внесён в sitemap и оба положительных каталога аналитики. Плавающие чат/CTA скрыты только на этой странице, чтобы не перекрывать интерактивные блоки.

## Проверка

- `npx tsc --noEmit` — успешно.
- `npm run build` — успешно, страница статически сформирована.
- 16 Node-тестов — успешно: 4 новых теста (26 граничных дат, все 366 дней, некорректные/будущие даты, високосные правила, комментарий CTA без даты рождения) и 12 существующих проверок согласий, API и аналитики.
- Синтаксис backend-каталога и наличие новой страницы проверены без изменения БД.
- Браузер: фактические React-компоненты страницы, Header/Footer, общая модальная форма и клиент API в изолированном QA-предпросмотре с адаптерами Next и mock API. Реальные заявки не отправлялись.
- Проверены 29.02.2000 → Рыбы, 21.03.1988 → Овен, 22.12.1990 → Козерог, будущая дата → ошибка и сброс старого результата; ручной выбор знака очищает дату.
- Пауза анимации проверена по кнопке и `animation-play-state: paused`. Реальная системная настройка reduced motion не менялась; её обработчик и CSS проверены в коде.
- Проверены desktop, 390 и 320 px; горизонтального переполнения нет (375/305 px контентной ширины с учётом скроллбара).
- Mock-заявка на Японию из результата Овна успешно отправлена с маршрутом, consent=true, consent_marketing=false, текущей версией согласия, credentials=omit и без даты рождения.
- Скриншот: `previews/astro-travel-2027-desktop.jpg`.
