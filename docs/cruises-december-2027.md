## Заявка

В каждой карточке кнопка «Уточнить цену и наличие» ведет в существующую форму
`/request` и передает название лайнера и выбранный день отправления.
Форма заполняет пожелания: лайнер, даты декабря 2027, длительность и два
взрослых. Названия принимаются только из списка семи лайнеров, день — 6–19;
неподходящие и повторяющиеся параметры игнорируются. Предзаполненный текст
можно изменить. Согласия и отправка через существующий публичный API сохранены.
Общие кнопки заявки работают без предзаполненного круиза, как прежде.

## Установка на существующий сервер

Миграций базы данных нет. Обновить backend для каталога аналитики и frontend
для страницы, изображений, навигации и формы:

```bash
cd /opt/sletat &&
git pull --ff-only origin master &&
docker compose -f docker-compose.prod.yml build backend frontend &&
docker compose -f docker-compose.prod.yml up -d --no-deps backend frontend
```

После обновления открыть `/tours/cruises-december-2027`, сменить дату в карточке,
проверить переход к форме с нужными пожеланиями и отображение на телефоне.
Обновление исходного кода в GitHub само по себе не обновляет контейнеры сервера.
