# Калининград: Новый год 2027 для семьи 2+1

Публичный адрес: /tours/kaliningrad-newyear-2027. Страница встроена в общий layout сайта, добавлена в раздел «Туры», sitemap и оба положительных каталога аналитики (frontend/backend).

Содержание перенесено из предоставленного владельцем Kaliningrad_NewYear_2027_Family_2plus1(1).html: 2 программы, 14 вариантов проживания/дат и 12 семейных расчётов перелёта. Возраст ребёнка фиксирован — 9 лет. Цены тура уже содержат наценку из исходного файла: повторная наценка не применяется. Международных курсов/внешних API поиска страница не использует. Базовая цена поставщика, названия операторов и внешние исходные ссылки не включены в публичные JSON. Программы, условия питания, доплаты и расположение гостиниц сохранены.

Цена билета с багажом заменяет цену без багажа, а не добавляется к ней. Календарные ориентиры отмечены отдельно; неподходящие рейсы 3 января из Саратова/Самары отмечены как требующие изменения перелёта/дополнительной ночи. Справочная сумма не включает стоимость исправления маршрута. Данные из подборки от 30.10.2026; новая проверка актуальных тарифов и наличия мест не проводилась. Страница не бронирует билеты.

CTA передаёт программе общей формы название тура, даты, состав семьи, гостиницу/номер, цену тура, город/багаж, расчёт авиа, сумму и предупреждение о несовместимости. Общая форма с существующими ссылками согласий: персональные данные обязательно, маркетинг отдельно необязательно. Проверка браузером использует QA-fixture с mock fetch и не создаёт лидов.

Проверено: Next production build, TypeScript, 5 тестов трекера; сверка всех 14 вариантов и 12 тарифов с вложением; выбор дат/гостиницы, календарный тариф без багажа, предупреждение по Самаре и передача параметров в форму. Аналитическая запись backend добавлена только в словарь разрешённых публичных адресов, без изменения моделей/миграций.

Установка: пересборка backend/frontend; backend нужен для приёма статистики нового адреса. Новых миграций/переменных окружения нет.
